# Contributing to QuickGPT

Thanks for your interest in contributing!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/FULL-STACK-AI-CHATBOT.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Set up the project following the [README](./README.md)

## Making Changes

- Keep changes focused and minimal
- Follow the existing code style
- Test your changes before submitting

## Submitting a Pull Request

1. Push your branch: `git push origin feature/your-feature-name`
2. Open a Pull Request against `main`
3. Describe what you changed and why

## Reporting Issues

Open a [GitHub Issue](https://github.com/Mohit20251/FULL-STACK-AI-CHATBOT/issues) with:
- A clear title and description
- Steps to reproduce
- Expected vs actual behavior
