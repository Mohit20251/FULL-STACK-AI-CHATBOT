# Changelog

All notable changes to this project will be documented here.

## [1.0.0] - 2025

### Added
- User authentication (register/login) with JWT
- AI chat powered by Google Gemini API
- Chat history with create/delete support
- Image upload via ImageKit
- Credit system with Stripe payments & webhooks
- Community page to browse published images
- Dark mode support
- Responsive sidebar navigation
- Deployment config for Vercel (client + server)
